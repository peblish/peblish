# Outbound requests: `isPublicAddress` and `safeFetch`

Every request to a host a person or a peer chose (federation delivery and fetches, link previews, the remote-media proxy) goes through `safeFetch` (`fetch.ts`). Nothing else in product code may call `fetch`, `http.request` or `https.request` on such a host. The S3 adapter is the one exception: its endpoint is operator configuration.

- `isPublicAddress(address)` (`public-address.ts`) is the one predicate. IPv4 special-purpose ranges and IPv6 special-purpose ranges are named constants with their RFC (`ipv4Ranges`, `ipv6Ranges`). An IPv4-mapped (`::ffff:0:0/96`) or NAT64 (`64:ff9b::/96`) address is judged by the IPv4 address inside it; the deprecated IPv4-compatible `::/96`, local-use NAT64 `64:ff9b:1::/48`, 6to4 `2002::/16`, Teredo and everything outside global unicast `2000::/3` are refused whole. Text that is not an address, an IPv6 zone and non-canonical IPv4 forms (`127.1`, `0x7f.0.0.1`) are not public.
- `safeFetch(url, init)` resolves the host once, requires every address to be public, and connects to those addresses (TLS and the Host header keep the original name), so DNS cannot answer differently between the check and the connection. It refuses credentials in URLs and schemes the caller did not list, follows at most `maxRedirects` hops (each one resolved and checked again; with 0 the 3xx comes back as it is), and keeps one deadline for the whole call. Headers that name a viewer (`Cookie`, `Referer`, `Origin`, `Authorization`, `Forwarded`, `X-Forwarded-*`, `X-Real-IP`, ...) are dropped whatever the caller passes. The response body is cut at `maxBytes` and `truncated` says so; a caller that cannot use half a body refuses it.
- `BlockedDestinationError` is permanent (never retry it). `FetchTimeoutError` and any other error are transient.
- There is no bypass. A test that needs a stub server on loopback builds its own client with `createSafeFetch({ resolve, isPublic })`; `fetch.test.ts` fails if any non-test source imports it. The local lab (lane LAB) adds its own path the same way.
